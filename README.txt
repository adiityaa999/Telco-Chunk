TELCO CUSTOMER CHURN PROJECT

Files:
- main.py: project code
- WA_Fn-UseC_-Telco-Customer-Churn.csv: dataset
- requirements.txt: libraries

RUN IN VS CODE:
1. Open this folder.
2. Open Terminal > New Terminal.
3. Run: pip install -r requirements.txt
4. Run: python main.py

The code saves every graph into output/graphs and saves model_comparison.csv and project_summary.txt inside output.
Plots are saved and closed automatically so the program can generate every output in one run.
